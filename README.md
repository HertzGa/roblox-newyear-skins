# Новогодний пак скинов для Roblox

Шесть образов на новогоднюю тему и сцена с санями: Дед Мороз, Снегурочка, Рудольф,
северный олень, эльф-почтальон и снеговик. Внутри — палитры, настройки тела,
поисковые запросы для Marketplace и скрипт, который собирает сани в Roblox Studio.

Пак фанатский: это не официальные ассеты Roblox и не аффилированный продукт.
Все цвета — ориентир, а не точные ID предметов: каталог меняется каждую неделю.

## Быстрый старт

```powershell
npx --yes serve .
```

Открой `http://localhost:3000/roblox-newyear-skins/`.

Страница использует ES-модули и three.js с CDN, поэтому при открытии двойным
щелчком (`file://`) браузер заблокирует модули. Нужен локальный сервер — `serve`,
Live Server в VS Code или любой другой.

Управление: ЛКМ — вращение, колесо — зум, `←` / `→` — переключение скинов,
кнопки справа — автоповорот и снег. Клик по цвету копирует HEX.

## Как собрать любой скин

1. Открой **Avatar Editor → Body**.
   - Body Type: `0–20` (блочное тело).
   - Height, Width, Head, Proportion — значения из карточки скина.
2. Собери одежду по палитре: клик по цвету в витрине копирует HEX, его можно
   вставить в редактор 2D-одежды или подобрать ближайший цвет в каталоге.
3. Открой **Marketplace → Community Creations** и найди аксессуары по запросам
   из раздела ниже. Английские запросы работают заметно лучше русских.
4. Надевай в порядке: тело → одежда → обувь → головной убор / рога → лицо →
   спина → аксессуар в руку.
5. Включи анимационный пакет, сохрани образ и проверь его в игре при дневном
   и ночном освещении.
6. Не забудь выключить лишние аксессуары: в Roblox одновременно можно надеть
   ограниченное число предметов одной категории.

Общие правила для всех скинов:

- **R15**, а не R6: у R15 нормально садятся накидки, рога и длинные шубы.
- Ширина тела `0–30%` — иначе шуба выглядит как коробка.
- Голова `100%` — маска или морда оленя должна сесть ровно.
- Не покупай «копии» с подозрительно низкой ценой: смотри на автора, дату
  публикации и отзывы. Дорогие limited-предметы подделывают чаще всего.

## Сцена «Сани»

Витрина показывает сани с полозьями, фонарём, подарками и упряжкой из двух
оленей — это стилизованная 3D-модель для превью, а не готовый Roblox-ассет.

В Roblox сани собираются скриптом `sleigh-build.lua`:

1. Открой Roblox Studio → новый Baseplate.
2. **View → Command Bar**.
3. Открой `sleigh-build.lua`, скопируй всё содержимое и вставь в Command Bar.
4. Нажми Enter. В Workspace появится модель `NewYearSleigh`.
5. Сядь на `DriverSeat` или двигай сани через `Model:PivotTo()`.

Скрипт безопасен: он не трогает другие объекты, только удаляет прошлую копию
`NewYearSleigh`, если она уже есть.

### Олени для упряжки

В витрине олени собраны из тех же примитивов: корпус `1 × 1.05 × 2.2`, шея под
углом ~30°, голова `0.9 × 0.74 × 0.95`, четыре ноги `0.36 × 1.7 × 0.4`,
рога — тонкие цилиндры. Цвета: шерсть `#6E6257`, морда `#D8CBB6`,
попона `#A5122A`, упряжь `#E6B45C`.

Два оленя ставятся перед санями на `z = 4.25`, `x = ±1.0`, масштаб `0.82`.
Поводья — тонкие цилиндры или `Beam` от переднего щита к сбруе.

## Частые ошибки

- **Скин не помещается в кадр.** Уменьши рост тела или надень аксессуары
  в другой категории: высокие рога и шляпы конфликтуют.
- **Белый костюм исчезает на снегу.** Добавь тёмный пояс, цветной шарф или
  золотые детали — контраст важнее точного цвета.
- **Мех выглядит как пластик.** В Roblox нет мягких материалов: выбирай
  аксессуары с текстурой меха, а не гладкие белые блоки.
- **Копия вместо оригинала.** Проверяй автора и цену; «free» на платный
  предмет — почти всегда перепродажа или подделка.
- **Сани не едут.** Скрипт делает декоративную модель: все детали Anchored.
  Раскомментируй блок с `WeldConstraint` в конце `sleigh-build.lua`.
